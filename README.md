# 総務部執行委員会 委員長サポート リポジトリ

委員長業務の補助として作成したアプリ・ツール・書類をまとめて保管する場所です。

## フォルダ構成

| フォルダ | 中身 |
| --- | --- |
| `apps/` | 作成したアプリ・ソフトウェア（1アプリ = 1フォルダ） |
| `docs/` | 書類・資料・アイデア整理メモなど |

## アプリ一覧

| アプリ名 | フォルダ | 概要 | 作成日 |
| --- | --- | --- | --- |
| PDF編集ソフト | [`apps/pdf-editor/`](apps/pdf-editor/) | ブラウザだけで動くPDF編集（結合・並べ替え・回転・削除・抽出、テキスト／画像／白塗り／ハイライト／ペンの書き込み） | 2026-11-20 |
