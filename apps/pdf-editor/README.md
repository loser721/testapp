# PDF編集ソフト（ブラウザ版）

サーバー不要、すべての処理をブラウザ内（クライアントサイド）で行うPDF編集ツールです。
PDFファイルが外部に送信されることはありません（ライブラリをCDNから読み込む通信のみ発生します）。

- 表示: [pdf.js](https://mozilla.github.io/pdf.js/) 3.11.174（CDN: jsDelivr）
- 書き出し: [pdf-lib](https://pdf-lib.js.org/) 1.17.1（CDN: jsDelivr）

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面本体 |
| `app.js` | アプリのロジック |
| `style.css` | スタイル |

## 起動方法

どちらの方法でも動きます。**インターネット接続が必要**です（pdf.js / pdf-lib をCDNから読み込むため）。

1. **ファイルを直接開く**: `index.html` をブラウザ（Chrome / Edge 推奨）にドラッグするか、ダブルクリックで開く。
2. **簡易サーバーで開く**:
   ```sh
   cd apps/pdf-editor
   python3 -m http.server 8000
   ```
   ブラウザで http://localhost:8000/ を開く。

## 使い方

### PDFを開く・結合する
- 「開く」でPDFを選択します（それまでの内容は破棄されます）。
- 画面中央にPDFをドラッグ＆ドロップしても開けます。**すでにPDFを開いている場合、ドロップしたPDFは末尾に追加（結合）されます。**
- 「PDFを追加」で選んだPDF（複数可）は、今のページの後ろに追加されます。

### ページ操作（左のサムネイル一覧）
- クリック: そのページを編集画面に表示し、選択します。
- Ctrl（Macは⌘）+クリック: 複数選択／選択解除。Shift+クリック: 範囲選択。「全選択」もあります。
- ドラッグ＆ドロップ: ページの並べ替え（1ページずつ）。
- 「⟲ 左回転」「⟳ 右回転」: 選択中のページを90度ずつ回転します。
- 「削除」: 選択中のページを削除します（確認ダイアログが出ます）。
- 「選択ページを抽出」: 選択中のページだけを別のPDFとして保存します（配置した要素も含みます）。
- 編集要素があるページのサムネイルには「編集 n」のバッジが付きます。

### ページへの書き込み（中央の編集画面）
上部のツールを選んで使います。キーボードでも切り替えられます（V/T/W/H/P）。

| ツール | 操作 |
|---|---|
| 選択 (V) | 要素をクリックで選択、ドラッグで移動。画像・矩形は右下の青い四角でサイズ変更（画像は縦横比を維持）。 |
| テキスト (T) | ページをクリックするとテキストが追加されます。右の「プロパティ」で文字・文字サイズ・色を変更（複数行可）。追加後は自動で「選択」ツールに戻ります。 |
| 白塗り (W) | ドラッグした範囲を白い矩形で覆います（修正液のような用途）。 |
| ハイライト (H) | ドラッグした範囲に半透明の色を重ねます。色は右の「ハイライト色」で設定。 |
| ペン (P) | ドラッグでフリーハンドの線を描きます。色・太さは右の設定で変更。 |
| 画像 | PNG / JPEG を選ぶとページ中央に配置されます。 |

- 要素を選択して **Delete** キー（または「この要素を削除」）で削除できます。
- 選択した要素の色・文字サイズ・ペンの太さは、右のプロパティ欄で後から変えられます。
- ズーム: 「－」「＋」「幅に合わせる」。

### 保存
- 「PDFを保存」で、ページの並び順・回転・削除と、配置した要素をすべて反映したPDFをダウンロードします。
- ファイル名は `<元のファイル名>_edited.pdf`（抽出は `_extract.pdf`）です。元のファイル名が英数字以外を含む場合は `document_edited.pdf` になります。

## 既知の制限

- **白塗りは「見た目を隠す」だけです。** 下にある元の文字や画像のデータはPDF内に残るため、テキスト抽出やコピーで読み取れます。個人情報などの墨消し（完全な削除）には使えません。
- **追加したテキストは画像として埋め込みます**（日本語を確実に表示するため）。そのため、書き出したPDFでは追加したテキストの検索・選択・コピーはできず、拡大すると多少ぼやけます（約288dpi相当）。
- 追加テキストのフォントは、使っているPCに入っている日本語フォント（ヒラギノ角ゴ／游ゴシック／メイリオ／Noto Sans JP など）です。画面表示と書き出しは同じ方法で描くので見た目は一致しますが、PCが変わると字形が変わることがあります。
- 元のPDFにもともとある文字や画像を直接編集することはできません（上から重ねて書き込む方式です）。
- 元に戻す（Undo）機能はありません。
- テキストとペンの線はサイズ変更ハンドルに対応していません（テキストは文字サイズで調整します）。白塗りの色は白で固定です。
- 要素を置いたあとでページを回転すると、矩形とペンの線はページの内容と一緒に回転します。テキストと画像は**位置だけが追従し、向きは正立のまま**です。
- サムネイルには配置した要素は表示されません（バッジで件数だけを表示します）。
- パスワード付き（暗号化）PDFは、開けないか、保存結果が正しくならないことがあります。パスワード入力画面はありません。
- 結合・保存では、しおり（アウトライン）が引き継がれません。フォーム入力欄は正しく動かなくなることがあります。
- JPEGのEXIF回転情報やCMYKのJPEGは、画面とPDFで向きや色が違う場合があります。
- 大きなPDF（数百ページ、数百MB）は、ブラウザのメモリ量によって重くなったり失敗したりする可能性があります。
- 動作確認は Chromium（ヘッドレス）だけで行っています。Firefox / Safari、タッチ操作（スマホ・タブレット）では確認していません。
